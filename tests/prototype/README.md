# startup-os 原型回歸測試

一條命令跑全套。所有測試都用隔離資料夾同假 AI（零費用），唔會讀寫原型嘅 `data/`，亦唔會對外發送任何嘢。

## 一條命令跑全套

喺專案根目錄（`AI-Native_Starup_Dashboard`）：

```
node tests/prototype/run-all.mjs
```

預設測試 `prototypes/proofread`。每項結果即時印出，最後印總數；全部通過先會以 0 結束。

測試對應最新版原型：新版仲喺程式副本、未換入時，用 `--proto <程式副本>` 測副本；換入後先用預設。用預設去測未換入嘅舊版，新功能嘅測試（例如經營節奏、每週訪問）會唔通過，唔係回歸。

## 設定（參數或環境變數）

| 參數 | 環境變數 | 預設 | 用途 |
| --- | --- | --- | --- |
| `--proto <資料夾>` | `SOS_TEST_PROTO` | `prototypes/proofread` | 要測試嘅原型（例如換入前嘅程式副本） |
| `--out <資料夾>` | `SOS_TEST_OUT` | 系統暫存資料夾入面 `startup-os-tests/<時間>` | 隔離資料夾、逐項紀錄、`summary.json`；唔可以喺原型資料夾入面 |
| `--chrome <路徑>` | `SOS_TEST_CHROME` | 自動搵本機 Chrome | 要瀏覽器嘅測試用（無頭模式） |
| `--port <起始埠>` | `SOS_TEST_PORT` | `4700` | 每項測試佔 10 個埠，自動避開 4318、4380、4381、4398、4402、4470、4471、4650，同埋 Fetch 標準封鎖嘅埠（例如 6000） |
| `--only <名稱>` | `SOS_TEST_ONLY` | 全部 | 只跑某幾項，逗號分隔，用名稱或者檔名（例如 `--only 每週訪問,rhythm-test`） |
| `--no-browser` | | | 唔跑要瀏覽器嘅測試（會標「未跑」，總結果唔算通過） |

搵唔到 Chrome 時，要瀏覽器嘅測試會標「未跑」，總結果唔算通過。

唔通過嘅測試會自動重試一次（機器忙時嘅時序問題）；重試通過會標「重試後通過」同第一次分數。有任何一項唔通過或者未跑，以 1 結束；全部通過以 0 結束。

## 工具（唔屬全套）

- 頁面文字掃描：`node tests/prototype/dashboard/page-scan.mjs <Chrome> <網址> <原型資料夾> <輸出 json> <Chrome 資料夾> [Chrome 埠] [預填編號]`，逐個頁面同未答問題包掃內部術語、口語字、不完整日期；有預填編號（資料夾 `ledger/prefill/` 入面一份）就另外掃交資料頁嘅預填狀態。
- 「你原話」標籤掃描：`node tests/prototype/tools/prefill-scan.mjs <data 資料夾> [輸出 json]`，獨立重新核對每份預填（標「文件原句」嘅要逐字喺封存文件搵到、出處要中）、每份交資料（同 AI 預填一樣嘅答案唔可以記成「你寫的」，同題要已確認）同公司概覽（AI 推斷唔可以標文件寫明）；零違規 exit 0，有違規 exit 1。
- 資料快照（只讀）：`node tests/prototype/tools/snapshot.mjs <data 資料夾> <標籤> <輸出 jsonl>`，記檔案數同最後修改時間。
- 換入核對：`node tests/prototype/tools/hashlist.mjs <程式資料夾> <SHA-256 清單>`，列出同清單比較改咗、新增、刪除嘅檔（唔包 `data/`）。

## 加新測試

1. 放入對應資料夾，參數沿用 `<原型資料夾> <輸出資料夾> <埠> <AI 設定>` 次序；要瀏覽器嘅加 Chrome 路徑。
2. 用隔離資料夾（`SOS_DATA` 指向輸出資料夾），唔好用真資料或者試走產出做夾具。
3. 最後一行印「通過數/總數」（例如 `12/12 通過`），失敗嘅行以 `FAIL` 開頭；全部通過以 0 結束。
4. 喺 `run-all.mjs` 嘅 `TESTS` 加一行。
