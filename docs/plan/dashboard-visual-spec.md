# startup-os 監察台視覺與動態規格

> **用途**：本檔是 `docs/plan/startup-os-PLAN.md`（下稱規劃書）第 4 節的配套數值檔，供實作者寫 `dashboard/dashboard.html`（監察台七個分頁）與 `dashboard/desk.html`（Founder Desk 四個畫面）的樣式、動畫與光流。規劃書定「顯示甚麼、可以按甚麼、狀態怎樣對應」；本檔只定「幾多像素、甚麼顏色、幾秒一次」。本檔可單獨閱讀：第 1 節先列會用到的狀態名稱與一句語義，詳細判定規則在規劃書 4.8、4.10、4.11、4.12。版面、導航與名稱由固定程式與名稱表產生，AI 只提供內容。
> **原則**：整頁只有深色主題；不載入任何外部字型或腳本；頁面沒有錄音或語音辨識程式（文字框接受系統語音輸入法）；光流由真實事件驅動，不是心跳；系統設定減少動態時全部動畫關閉。

## 1. 會用到的狀態名稱

| 範疇 | 狀態 | 一句語義 |
|---|---|---|

| 伺服器身份 | `instance` 變更 | 伺服器重啟過：頂部橫條「重新載入」、停止送出（規劃書 4.9） |
| 手機配對 | 等待掃碼 / 待接受 / 已連上 / 連不上 | 「用手機開」後二維碼顯示中／手機已配對、等電腦接受（橫條附確認碼、接受與拒絕）／電腦已接受（橫條附撤銷）／手機頁連線中斷（全屏指引）；規劃書 4.9 手機模式 |

## 7. 減少動態與暫停

- `prefers-reduced-motion`：所有 `animation`、`transition` 設 `none`，畫布透明度 .5；JS 以此初始化 `paused = reduced = true` 並加 `body.paused`；按「暫停動效」只彈提示「系統已設定減少動態；頁面保留靜態閱讀」，不切換。一般模式下「暫停動效」加 `body.paused`：停止全部動畫與粒子，保留靜態路線，事件流新行只保留琥珀邊不淡出，慶祝只更新數字與顏色不播。
- 沒有巡覽焦點、閱讀焦點或「定位工作」（規劃書 4.7 刻意不放）：工具列右側只有連線徽章與「暫停動效」；鍵盤焦點外框（薄荷 2px）是唯一的焦點樣式，與工作信號互相獨立。
