# 問題包格式（startup-os.ask/0.1）

用途：AI 需要創辦人決定或者提供資料時，唔好喺對話逐題問，而係寫一個「問題包」。創辦人喺 Founder Desk（startup-os 嘅決定頁面）每次只答最重要嘅 3 條，其餘照 AI 建議先咁計住，之後再問。適用於任何階段：業務、產品、推廣、研究、關鍵決定。

公司概覽（AI 按 `company-page-format.md` 擬，外殼核對後放喺資料夾嘅 `company/page.json`）係同一套題目格式嘅特例：多咗「路線」同「細節」兩部分，「要你決定」三條就係佢嘅 `decide.items`。

## 出題規則（AI 一定要守）

1. **先問會改變你下一步工作嘅**：用 `priority` 排，1 最重要。唔影響下一步嘅唔好問。
2. **每條一定要有 AI 建議同一句理由**：`value` 係你嘅建議答案，`why` 係點解。創辦人可以一撳照用。
3. **AI 自己搵得到嘅唔好問**：查得到嘅資料自己查；只問創辦人先知、或者要創辦人拍板嘅。
4. **一條只問一件事**，問題（`ask`）用日常白話；唔出現術語、檔案路徑、編號；選項最多 3 個。**標題（`title`）係名稱，一律用書面語**，唔可以有口語字（例如嘅、咗、唔、喺、係、睇、揀、而家、邊個）：例如寫「約見綠野物流前的待決事項」，唔好寫「約綠野物流見面之前要你決定嘅事」。命令入口會退回有口語字嘅標題；AI 流程入面會記低警告。畫面上嘅固定名稱見 `names.js`。
5. **標明效力**：`effect: "tentative"`（先咁計住，之後可以再問，預設）或者 `"now"`（確認後即刻生效，例如對外承諾、花錢、改目標）。`now` 一定要有選項，唔可以淨係自由文字；`now` 嘅題目一定排喺第一批逐條問，唔會跟「照 AI 建議」一齊帶過，所以一個包最多 3 條 `now`。
6. **一個包最多 12 條**。多過 12 條，系統會按 `priority` 自動拆成幾個包；你應該先問自己：真係要問咁多？
7. **答過嘅唔好再問**：系統會對照紀錄，同一條問題答過就自動拎走。
   **只有創辦人知道嘅事**（例如會面幾點開始、對方講咗乜）：你估唔到就將建議寫成「不知道／稍後提供」，唔好寫「要你提供」「請填寫……」呢類提示句（系統見到都會自動改）。創辦人答「不知道／稍後提供」嘅事，一星期內唔好再問，亦唔好換個講法再問；工作說明會列出呢啲事。每條題可以加 `about`，用幾個字寫明問緊邊件事（例如「與綠野物流會面的開始時間」），系統靠佢認出同一件事。
8. **建議唔可以同公司概覽矛盾**：出題前先讀公司概覽（創辦人確認咗嘅答案為準）；目標客戶、價錢、伙伴狀態等要跟佢。有矛盾就將矛盾變成一條問題，唔好自己估。

9. 免除 AI 腔：唔好客套開場、唔好收尾總結或者主動提議、唔好空泛形容詞同口號。所有畫面會見到嘅字（報告、問題、選項、理由、標題）唔可以有內部工程術語，例如 G 編號、run、sandbox、ledger、檔案路徑、id。外殼會檢查，命中會叫你改寫。

## 格式

```json
{
  "format": "startup-os.ask/0.1",
  "title": "約見綠野物流前的待決事項",
  "context": "一句講點解要問：AI 準備緊約見同簡介，有幾樣要你拍板。",
  "afterConfirm": "一句講答完之後 AI 會即刻做乜",
  "next": { "task": "答完之後 AI 要繼續做嘅工作（一段說明）；冇就省略 next" },
  "questions": [
    {
      "id": "meet-date",
      "priority": 1,
      "ask": "幾時約綠野物流見面？",
      "judge": "一句判斷標準，可以省略",
      "kind": "date",
      "value": "2026-11-05",
      "why": "簡報已準備好；一星期內約到，11 月底前先有答覆。",
      "effect": "tentative"
    },
    {
      "id": "who-joins",
      "priority": 2,
      "ask": "見面邊個一齊去？",
      "kind": "choice",
      "options": [
        { "text": "我自己", "rec": true },
        { "text": "我同何師傅", "note": "示範廚藝專業" }
      ],
      "value": "我自己",
      "why": "第一次見面先了解意向，唔使出動太多人。"
    }
  ]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `format` | ✓ | 固定 `startup-os.ask/0.1` |
| `title` | ✓ | 60 字以內，書面語，講清楚係關於乜 |
| `context` |  | 一句點解要問 |
| `afterConfirm` |  | 一句答完之後 AI 會做乜（頁面會顯示） |
| `next.task` |  | 答完之後要 AI 繼續做嘅工作；有就會自動叫 AI 繼續 |
| `questions[].id` | ✓ | 英數、`-`、`_`，包內唯一 |
| `questions[].priority` |  | 數字，1 最先問；冇就按次序 |
| `questions[].ask` | ✓ | 問題，一句 |
| `questions[].judge` |  | 判斷標準，一句 |
| `questions[].kind` |  | `choice`（揀一個，可自己寫，預設）／`multi`（揀幾個）／`date`（揀日子）／`text`（自己寫） |
| `questions[].options` | `choice`／`multi` 要 2–3 個 | `{ "text", "rec"?, "note"? }`；`rec: true` 係 AI 建議 |
| `questions[].value` | ✓ | AI 建議答案；`multi` 用陣列；`date` 用 `YYYY-MM-DD` |
| `questions[].why` | ✓ | AI 點解咁建議，一句 |
| `questions[].effect` |  | `tentative`（預設）或 `now` |
| `questions[].src` |  | 出處，例如 `[{ "from": "生意構思", "at": "第七節" }]` |
| `questions[].about` |  | 幾個字寫明問緊邊件事（畫面唔顯示）；用嚟認出同一件事，唔好重問 |

## 點樣交出去

- **AI 做緊嘢時**：將問題包寫入 `out/ask.json`，外殼核對後會放上 Founder Desk「等你決定」。
- **任何時候（命令）**：`node ask.mjs <問題包.json>`，會開頁面畀創辦人答。
- **Claude Code**：`adapters/claude-code/startup-os/` 係技能（skill）接口：創辦人打 `/startup-os:desk` 或者講「打開 Founder Desk」就會打開；AI 要創辦人決定時亦會自己用佢出題。
- **打開 Founder Desk（唔出題）**：`node ask.mjs --desk`；冇開就喺背景開，唔使任何視窗。
