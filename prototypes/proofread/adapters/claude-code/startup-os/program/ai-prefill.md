# 你今次嘅工作：按文件預填交資料首五條

創辦人喺 Founder Desk 交資料頁加入咗文件，想你按文件預填首五條必填題。同一個資料夾：

- `files/`：創辦人加入嘅文件（只可以讀）。
- `questions.json`：五條題目（`id`、問題、提示）。

你只做一件事：讀文件，逐條預填。**唔好擬公司概覽，唔好建任何問題包，唔好寫其他產出。**

## 規矩（一定要守）

1. 只可以讀寫呢個資料夾；只寫 `out/prefill.json`。
2. **原句優先**：文件有直接講到嘅，照抄文件原句（可以抄一至三句，一字不改，包括標點），`quote` 寫 `true`，`source` 寫檔名，`at` 寫喺文件邊一節（標題或者頁數）。
3. 文件冇原句、要你歸納或者推斷先答得到嘅，用一兩句書面語寫，`quote` 寫 `false`，`source` 寫主要根據嘅檔名。**唔可以將你寫嘅句子標成原句。** 外殼會逐字喺文件核對，核對唔到嘅會改為「AI 按文件推斷」。
4. 文件完全冇講嘅題，`text` 留空，唔好估。
5. 第 3 題（目前進展）只寫公司以外已經發生嘅事；文件冇講已發生就留空。
6. 唔好寫文件冇嘅人名、數字、日期或者承諾。
7. **按今日日期判斷**：工作說明第一行有今日日期。文件寫「本週」「今日」「下星期」或者某個日子，先對照文件日期同今日日期；已經過咗嘅事唔好寫成仲未發生（例如「本週安排三場會議」而三場都已過，就寫「三場會議日期已過，文件未有結果」，`quote` 寫 `false`）。照抄原句時亦一樣：原句講嘅時間已過，就改用按文件推斷。

## 要交

`out/prefill.json`（只可以係有效 JSON）：

```json
{
  "answers": {
    "q1": { "text": "文件原句或者你寫嘅一兩句", "quote": true, "source": "檔名.md", "at": "邊一節" },
    "q2": { "text": "", "quote": false, "source": "", "at": "" }
  }
}
```

`q1` 至 `q5` 每條都要有；冇資料嘅 `text` 留空。做完就停。
